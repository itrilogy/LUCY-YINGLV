# 参数化视听生成平台（Parametric Audio-Visual Engine）产品需求文档 (PRD)

## 1. 产品定位与商业目标

* 产品定义
  1. 本产品是一套面向专业音乐人、数字媒体艺术家、广告厂牌及卡拉OK内容制作者的“**代码驱动型参数化高保真音乐视频（Code-rendered Music Video）端到端生产平台**”。
  2. 区别于传统以关键帧为中心的手工剪辑软件（如 After Effects）或轻量 DOM 合成工具（如 Remotion），本产品以“**纯数学时间映射函数与三维着色器几何流形**”为核心，输出具备 60 FPS / 4K 广播级画质、亚像素物理抗锯齿与自适应动态蒙特卡洛运动模糊的顶级视听艺术母带。

* 核心价值主张（Value Propositions）
  1. **生产成本降维**：将工业级三维代码排版音乐视频的制作周期由传统的 2~4 周手工研发压缩至 30 分钟自动化端到端产出。
  2. **画质突破瓶颈**：完全由 GPU 着色器在物理分辨率逐像素解算，彻底杜绝视频素材放大失真与拉伸伪影，实现 true-4K 极限锐度。
  3. **资产复利增殖**：通过“主干流水线自动化装配 + 旁路人机标准化资产工厂”机制，每一次冷门意象的人机协同孵化均直接沉淀为全系统可复用的终身资产。

## 2. 用户角色与典型使用场景

* 用户角色画像
  1. **独立音乐人 / 厂牌主理人**：拥有完成母带的音频文件（WAV/MP3）及歌词文本，预算有限，需快速为新单曲发行制作宣发级 4K 视觉 PV。
  2. **新媒体运营 / 短视频创作者**：需批量制作高质量卡拉OK排版或具有视觉冲击力的动态海报切片（TikTok / Reels / Bilibili）。
  3. **着色器工程师 / 视觉设计师**：作为资产创作者参与平台旁路生态，编写可插拔的 `VisualEffectPlugin` 图元并获取商业分成。

* 核心用户场景（Use Cases）
  1. **场景一：全自动单曲交付（Zero-touch Run）**
     * 用户上传《歌曲.wav》和《歌词.lrc》，选择“极简工笔科技”或“赛博暗黑对冲”宏观风格基调。
     * 系统在 3 分钟内完成音频分轨解构、节拍网格拟合、歌词强制对齐，并在现有图元库中完成智能匹配组装，启动分布式云渲染，输出成品 4K MP4。
  2. **场景二：缺料触发与人机资产增殖（HITL Asset Factory Run）**
     * 用户输入的歌词包含极冷门的哲学意象（如“量子纠缠的无量劫”），系统检测到图元库匹配余弦相似度低于阈值，自动生成资产赤字工单。
     * 签约视觉工程师或驻场专家在审核后台接收工单，LLM 生成候选 WebGL 片元代码，沙箱自动排错与无头截帧，工程师微调参数一键签署入库。
     * 主流水线自动解挂，完成最终高品质渲染，该图元永久注册至公共库。
  3. **场景三：参数化微调与交互式实时预览（Web Preview Tweaker）**
     * 用户在浏览器内以 60 FPS 实时预览任意时间轴切片，通过滑块微调后处理泛光阈值、胶片颗粒度或强调色配色方案，确认无误后提交云端导出。

## 3. 功能需求规格说明（Functional Requirements）

### 3.1 模块一：音频与文本多模态解构服务（Ingestion & Analysis Service）
* 功能输入规范
  1. 音频格式支持：WAV (16/24/32-bit float, 44.1kHz~96kHz)、FLAC、MP3 (128~320kbps)。
  2. 歌词格式支持：LRC（带行时间戳）、SRT、TXT（纯文本，自动按标点/换行断句）。
* 功能处理逻辑
  1. **音轨解构引擎**：调用 Demucs `htdemucs_ft` 4轨分离，结合 Mel-Band RoFormer 提纯主唱干声。
  2. **声学特征解算**：以 100 FPS 频率输出多频段带通滤波能量包络（RMS/Low/Mid/High）及乐器离散瞬态脉冲（Kick/Snare/Hi-hat）。
  3. **节拍时钟自拟合**：执行全曲频域自相关分析，输出全局恒定 BPM 或变动节拍曲线（Tempo Map），建立连续小节（Bar）与拍号（Beat Phase）网格。
  4. **CTC 约束强制对齐**：基于 Meta MMS 与 Wav2Vec2 双声学模型发射概率融合，辅以 Whisper 时间戳校验与清辅音/谱通量信号微调，产出词级（Word）与音节级（Syllable）绝对起止时间戳及对齐置信度。
* 功能输出规范
  1. 产出强类型 `audio.json` 与 `lyrics.json` 数据契约。

### 3.2 模块二：视听语义编排与时间轴编译器（Smart Orchestrator）
* 意象抽取与本体极性打标
  1. LLM 接收词级歌词文本，输出结构化实体意象向量及 12 维古代对仗与哲学二元极性得分向量（涵盖虚实、显隐、升沉、聚散、昼夜、动静等）。
  2. 根据音频段落动态曲线自动识别音乐宏观结构：`intro`、`verse`、`pre_chorus`、`chorus_drop`、`bridge`、`outro`。
* 组合范式决策与冲突消解
  1. 依据 6 大核心工业组合范式（冷调工程、克苏鲁暗黑、指数爆炸、工业异化、哲学空无、递归织机）进行分段指派。
  2. 施加同质化抑制：同一视觉范式连续命中不得超过 2 个镜头。
  3. 色彩张力守恒：自动生成包含 `C_INK`、`C_BONE`、`C_SIGNAL`、`C_GRAPHITE` 的全局线性 HDR 色相矩阵，主色全曲冻结，强调色平滑演进。
* 时间轴 DSL 编译
  1. 输出完全解耦的 `timeline.json`，声明各镜头的起始物理时间、加载的图元插件 ID、镜头运镜修饰器及 Uniform 绑定映射参数。

### 3.3 模块三：标准化人机交互资产增殖工厂（HITL Asset Factory）
* 赤字检测与工单生成
  1. 当某镜头最佳图元余弦相似度 $\cos(\mathbf{e}_{\text{lyric}}, \mathbf{p}_{\text{preset}}) < 0.72$ 时，自动拦截并挂起该分镜，发出 `AssetDeficitTicket`。
* 代码生成与沙箱自愈
  1. 组装包含引擎底层 API 签名（`Scene`、`Frame`、`FSPass`、`LineBatch`）、物理硬约束规范及该镜头声学切片参数的提示词脚手架。
  2. 调度代码大模型生成 TypeScript + GLSL 代码。
  3. 沙箱环境自动执行 `tsc --noEmit` 静态类型核验与独立 GLSL AST 解析；若报错捕获 `stderr` 执行最多 3 轮自动 Reflexion 修复。
* 无头渲染测试与性能看门狗
  1. 无头 Chromium 自动加载代码，调用 `render.ts stills` 渲染 16 格均匀时钟接触表（Contact Sheet PNG）。
  2. 运行 60 帧压测，硬性核验性能指标：单帧耗时 $\le 16.6\text{ ms}$、Draw Calls $\le 15$、显存泄漏检测为 0。
* 人机审查终端（Review Console）
  1. 提供轻量 Web 工作台展示代码、接触表、性能耗时雷达图。
  2. 审查员拥有原子操作权限：`Approve`（签名入库）、`Tweak`（在线滑块调试）、`Reject`（自然语言批注退回重绘）。
* 自动打标入库
  1. 提取插件暴露的参数自动编译为 `JSONSchema`。
  2. 计算语义向量并注册至图元向量数据库，解除主干流水线挂起状态。

### 3.4 模块四：确定性图形渲染与分布式导出引擎（Render Engine & Exporter）
* 浏览器端实时交互播放器
  1. 采用 Three.js + WebGL2 构建确定性时序总线，任何时间戳 $t$ 画面为歌曲物理时间的纯函数。
  2. 支持按键快进、快退、单帧步进（`,` / `.`）、小节循环（`l`）与 UI 隐退，具备热更新重载能力。
* 云端分布式切片渲染管线（Distributed Chunk Renderer）
  1. 支持将作品按小节划分为若干独立分段切片（Chunks，每个 15~30 秒）。
  2. 节点采用无头 Chromium 驱动硬件加速，通过 WebGL2 PBO / Fence 异步回读原始 RGBA 像素缓冲。
  3. 采用带滑动窗口（`inflight <= 4`）的 WebSocket 二进制流控通道，向宿主 FFmpeg 进程灌入字节流，防止 4K 内存 OOM。
  4. FFmpeg 采用 libx264（CRF 16~20, preset slow, tune grain, yuv420p）完成视频压缩，并在母节点执行二进制无损级联（`-c copy`）拼接与音频合流。

## 4. 非功能性需求（Non-Functional Requirements）

* 性能指标（Performance SLA）
  1. **实时预览帧率**：1080p 分辨率下，在主流终端（M1/M2/M3 Mac 或 RTX 3060 以上 PC）平稳维持 $\ge 58\text{ FPS}$，单帧渲染耗时 $\le 16.6\text{ ms}$。
  2. **4K 离线渲染吞吐率**：在配备单张 NVIDIA A10G (24GB) 的云端节点上，1080p60 渲染速度不低于 15 FPS；4K60 渲染速度（自适应采样 36 子帧均值下）不低于 2.5 FPS。
  3. **分布式总耗时**：全曲 3 分钟 4K60 视频，在 8 节点分布式切片并发渲染架构下，从提交任务到最终 MP4 母带交付总耗时 $\le 6\text{ 分钟}$。

* 质量与稳定性（Reliability & Quality）
  1. **确定性与像素一致性**：相同输入、相同时间戳 $t$ 下，不同节点导出的画面像素级完全一致（PSNR $\ge 60\text{ dB}$，SSIM $\ge 0.999$）。
  2. **内存硬红线**：单个渲染 Worker 进程内存上限严格锁死在 8 GB，绝不发生长尾 OOM 崩溃。
  3. **沙箱故障隔离**：任意新图元着色器崩溃必须被沙箱拦截，绝不允许非法插件污染主引擎 WebGL 上下文。

* 安全性与版权合规（Security & Compliance）
  1. **代码注入防御**：生成的 TypeScript / GLSL 插件在独立容器或 WebWorker 沙箱中运行，禁止访问宿主 DOM、Cookie 及非图形 Web API。
  2. **字体与资产合规**：全平台仅集成具备商用开源授权的字体（SIL OFL 协议）与数学轮廓字体（Hershey / EMS Public Domain）。

## 5. 产品版本迭代路线图（Milestones）

* Phase 1：MVP 引擎标准化与参数解耦（M1 ~ M3）
  1. 彻底移除现存代码库中的硬编码歌词检索，完成核心通用引擎与单曲业务场景的物理分离。
  2. 建立标准 `VisualEffectPlugin` 接口规范与首批 20 个高保真预制图元池。
  3. 实现数据驱动的 `timeline.json` 解析与渲染调度。

* Phase 2：自动化编排与云端切片渲染验证（M4 ~ M6）
  1. 上线端到端 Python 音频解构微服务（Demucs + CTC + Librosa）。
  2. 搭建基于意象标签与二元对仗本体论的智能编排器。
  3. 实现基于 AWS ECS Spot 实例与 FFmpeg 无损级联的切片并行分布式渲染，全曲 4K 交付压制至 10 分钟内。

* Phase 3：标准化人机资产工厂与商业化 SaaS 开放（M7 ~ M9）
  1. 上线 `Asset Factory Sidecar`，完成沙箱预编译、接触表生成与审查控制台开发。
  2. 开放资产创作者平台，支持第三方着色器工程师提交插件并进行多维向量入库。
  3. 商业化上线面向大众创作者与厂牌的订阅制/按次付费 API 服务。
